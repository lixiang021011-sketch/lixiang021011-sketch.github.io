工坊从哪来，图是怎么留下来的

2026-09-20 建的 Icon Studio。要给 Unity 出 HUD 图标，不能模型出一张就进游戏。 所以先做工坊：风格圣经、出候选、规格检查、人工审阅、版本、导出。下面按那天起到现在排，用当时的图。

FallenAngel 设计稿十六件里，谱架、铅笔、抄歌本这三件有稿，成果段不放。

1. 为什么要做工坊

当天对话里项目定名 icon-studio，导出优先对接 Unity。README 写的流程是：风格圣经 → GPT Image 2.5 出候选 → 规格检查 → 人工选择/精修 → 版本 → 导出。 「生成 10 资产候选」会打真实接口，停在人工选择，不会自动采用。

工坊页面就是按这个闸门拆的：任务、审阅、风格圣经、对照实验、导出。规格检查看画布、透明底、主体、安全边距。 按钮/边框另走精确 SVG，道具图标不走 SVG。

闸门从第一天就定了：模型出草稿，人点 keep，才许进 Unity。

2. 第一天：GPT Image，十个代表件

项目当时叫「水月肉鸽」，风格圣经「水月深蓝」。探针是通用 HUD：长剑、盾、药水、金币、生命、地图、宝箱、星章、法典、钥匙。 每件三张（典范 / 纹饰 / 克制）。模型 gpt-image-2.5-flare，quality max，单张约 $0.21。时间 11:11–11:18 UTC。

长剑三变体

十件典范

判定：能出、能认。按张付钱。风格是深海 HUD，不是后来要带上路的东西。

3. 当天下午接本地 Comfy

18:42 管线自检：Comfy 还没起来（fetch failed），精确 SVG 和 Unity 包过了。 20:50 第一张本机 SDXL + 自制 LoRA「铜绿纹章」：透明底过了，安全边距没过（包围盒贴边）。

判定：本地能出。自制纹章补丁物体识别偏弱。云端按张付的路不再作为主路径。

4. 水月圣经叠图标 LoRA

仍用剑 / 药水 / 音符。先叠 gameicon_sdxl，再对照 RPG Item Icons、RPG Weapon Icons、Underwater。

判定：本地补丁能改画风。水月深海 + 商店图标，还是不像随身物件。于是换题材：复读机、热水袋，并开始扫气质 LoRA。

5. 先换气质 LoRA

同一件复读机，四把材质/年代 LoRA。看的是「像不像这个游戏的东西」，还不是图鉴规格。

判定：气质有了，还不是单件图鉴。

6. 再换图标笔

Game Icon Forge、RPG Item Icons。短提示，测补丁本身。

判定：像商店图标，不像会带上路的东西。

7. 贴纸单贴 / 小表

Sticker Sheet。试过切开散图这条路。

判定：能切，但是贴纸，不是藏品。

8. 换手绘介质

同一件，插画 / 马克笔 / 水粉。

判定：水粉留下。后面物件都走水粉 LoRA 图生图，不再换介质。

9. 实物图生图，扫 denoise

热水袋。太低像照片，太高身份漂。后来藏品批次也是同一套扫法（耳机 0.55 / 0.64 / 0.72）。

判定：按件选 denoise，不是全局一个数。热水袋留 0.68，耳机留 0.55。

10. 扣透明底，退回

试过把纸底扣掉。复读机早期 lock set 扣过一轮；十六件定稿后又灌过一轮。主体被咬，void 从目录里丢掉，keep 仍是实心底。

判定：扣底不做。进游戏的是实心底那张。
